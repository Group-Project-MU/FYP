<h1>Advanced Nmap Scanner · User Guide</h1>
<div class="container">
   <p>Welcome! This guide will help you understand and use the scanner effectively — whether you are a beginner exploring networks or a professional looking for quick vulnerability insights.</p>
</div>
<h1>1. Introduction – why use this scanner?</h1>
<div class="container">
   <p>This project aims to develop a user-friendly graphical interface with clear guidelines through Nmap for the users who lack experience using network scanning tools to improve cybersecurity. </p>
   <p>Network scanning helps you discover loopholes before an attacker does. An open port with weak firewall rules can become an entry point for malicious actors. This scanner is designed especially for beginners who have limited experience with Nmap, but it also offers advanced features for power users.</p>
   <p>The application provides a clean graphical interface (built with PyQt6) and organises scan results into easy‑to‑read tables, graphs, and vulnerability dashboards. You can perform quick checks or deep inspections without memorising Nmap command-line switches.</p>
</div>
<h1>2. Installation & requirements</h1>
<div class="container">
   <p>Before you start, make sure the following components are installed:</p>
   <ul>
      <li><strong>Python 3.8+</strong> – the core language.</li>
      <li><strong>Nmap</strong> – the scanning engine. <br>
         <span style="color:#444;">Windows users: download from <a href="https://nmap.org/download.html">https://nmap.org/download.html</a> and remember the installation path (e.g. <code>C:\Program Files (x86)\Nmap\nmap.exe</code>).</span>
      </li>
      <li><strong>Required Python libraries</strong> – python-nmap, PyQt6, vulners, ipaddress, matplotlib, requests, beautifulsoup4, openai, etc.</li>
   </ul>
   <p><strong>Automatic installation:</strong> No worry! The program includes a helper script that reads <code>requirements.txt</code> and installs all dependencies.</p>
   <div class="note">
      <strong>Note:</strong> The vulnerability dashboard uses the <strong>Vulners API</strong> (free tier: 100 credits/month). The <strong>default key is for demo use only</strong>, you should register your own account from
      <a href="https://vulners.com/">https://vulners.com/</a> and obtain your own key from <a href="https://vulners.com/userinfo?tab=api-keys">https://vulners.com/userinfo?tab=api-keys</a>.
   </div>
</div>
<h1>3. Getting started – first launch</h1>
<div class="container">
   <p>When you initially start the program, an onboarding guide will guide you how to use the program. You can also find it in setting.</p>
   <p>The GUI is divided into <strong> 4 Main Panel </strong>:
   <ul>
      <li><strong>Top panel</strong> – utility bar that contains export, help and setting.</li>
      <li><strong>Left panel</strong> – contains all commonly used functions, history hidden/show button and the home/exit buttons.</li>
      <li><strong>Centre panel</strong> – shows your scan history.</li>
      <li><strong>Right panel</strong> – displays the vulnerability dashboard by default: latest CVEs, top 5 vulnerabilities, Hong Kong's security alert, and a graphical distribution for the vulnerabilities.</li>
   </ul>
</div>
<h1>4. Scan types – what each button does</h1>
<div class="container">
   <p>The quick functions(left sidebar) groups the core functions. You may refer to the table below:</p>
   <ul>
      <li><strong>Home</strong> – returns to the main vulnerability dashboard.</li>
      <li><strong>Quick scan</strong> – performs host discovery, scans the most popular ports (top 1000), and detects service versions. Ideal for a fast overview.</li>
      <li><strong>Comprehensive scan</strong> – scans all 65535 ports (TCP), detects versions, and OS detection. Aims to obtain a complete result.<br><strong style="color: #5a4e1e;">This can take several minutes.</strong></li>
      <li><strong>Vulnerability scan</strong> – runs Nmap’s vulnerability scripts (NSE) and also queries the Vulners database for known CVEs matching the services found. Results include CVE IDs, CVSS scores, and descriptions. Instead of viewing the information from the database, we also provided an AI result to provide the solutions about the scanned possible vulnerabilities.</li>
      <div class="note"><strong>Note:</strong> Vulnerability scan is time-consuming, we recommend scanning a single device at a time!</div>
      <li><strong>Custom Scan</strong> – You can type any Nmap script argument (e.g. <code>http-enum</code>, <code>smb-os-discovery</code>) or select the Nmap script, and it will be appended to the scan.</li>
      <li><strong>Exit</strong> – closes the application.</li>
   </ul>
</div>
<h1>5. Input formats – what you can scan</h1>
<div class="container">
   <p>The program accepts three types of targets. It validates your input before starting any scan.</p>
   <h3>Single IP address</h3>
   <p>Example: <code>192.168.1.1</code> – standard IPv4 format. The validator checks that each octet is between 0 and 255.</p>
   <h3>Website (domain)</h3>
   <p>Example: <code>example.com</code> or <code>scanme.nmap.org</code>. The program resolves the domain. if it doesn’t exist, you’ll see an error message.</p>
   <h3>IP range</h3>
   <p>Example: <code>192.168.1.1-254</code> – scans all addresses from .1 to .254. The range part is checked to ensure it lies within 0–255.</p>
   <div class="note">
      <p style=" color: #5a4e1e;"><strong>Note:</strong> Invalid inputs (e.g. <code>300.1.1.1</code>, <code>abc.def</code>) are rejected immediately – no scan is started, and a clear error is shown. You <strong>SHOULD NOT ENTER</strong> the <strong>IP address end with 0 or 255</strong>.</p>
   </div>
</div>

<h1>8. Troubleshooting & logs</h1>
<div class="container">
   <p>If something unexpected happens, the program records error details in a log file (<code>scanner_log.log</code>) located in the application folder. Check it for hints – common issues include:</p>
   <ul>
      <li><strong>Nmap not found</strong> – you haven’t set the correct path in Windows, or Nmap is not installed. Go to <em>Config file → Set Nmap path</em>. You may also restart the application to reselect the path.</li>
      <li><strong>Vulners API limit reached</strong> – the free monthly credits may be exhausted. The dashboard will not show anything except the error message. You can wait until next month or provide your own API key in the configuration file.</li>
      <li><strong>Scan freezes on comprehensive scan</strong> – some networks or firewalls may cause delays, the progress bar reassures that the scan is still running. If it hangs indefinitely, restart the app.</li>
      <li><strong>Invalid input not caught?</strong> – make sure you use dots and hyphens correctly. The validator follows strict IP rules.</li>
   </ul>
</div>
<h1>9. Frequently asked questions (FAQ)</h1>
<div class="container">
<h3>Do I need to know Nmap commands?</h3>
<p>No. The quick, comprehensive, and vulnerability scans work out‑of‑the‑box. Custom scan is optional.</p>
<h3>If the scanner scanned me open several ports, should I turn them off?</h3>
<p>Not necessarily. Not all open ports are dangerous, but every open port represents a potential attack surface.</p>
<h3>If a port shows "low" risk level, does it really mean 100% safe?</h3>
<p>Not necessarily. Encryption is similar to putting your letter in a sealed envelope. It ensures the content is not accessed by anyone other than the recipient, but it may contain a harmful request. A hacker may still send dangerous instructions to your server even with an encrypted connection. It just safeguards the delivery process, the server's/host's security settings and software updates must be done.</p>
<h3>How often is the CVE database updated?</h3>
<p>The dashboard queries the Vulners API live, so you always see the latest information (subject to API credits).</p>
<h3>Can I scan my whole local network?</h3>
<p>Yes – use the IP range format, e.g. <code>192.168.0.1-254</code>. Be aware that a full port scan on many hosts will take time.</p>
<h3>Where can I find the exported CSV files?</h3>
<p>A file dialog asks you where to save.</p>
